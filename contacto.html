Preguntas Frecuentes

¿Cuánto tiempo toma crear mi página web?

Depende del tipo de servicio: Web Simple (3-5 días), Landing Page (2-4 días), Rediseño Web (5-7 días). Una vez que recibimos toda la información y contenido necesario.

¿Qué incluye el precio del servicio?

Cada servicio incluye diseño responsivo, 3-5 páginas (Inicio, Sobre Nosotros, Servicios, Contacto, etc.), optimización SEO básica, formulario de contacto, integración con WhatsApp y hasta 3 rondas de revisiones. El hosting y dominio son incluidos.

¿Puedo actualizar mi página web después?

Sí, totalmente. Si deseas encargarte tú mismo de actualizar tu página web y tienes los conocimientos para hacerlo, tendrás acceso completo sin ninguna limitación. La web es tuya y podrás modificar textos, imágenes o secciones cuando lo necesites.
Y si no sabes cómo hacerlo o prefieres que nosotros lo gestionemos por ti, ofrecemos servicio de mantenimiento desde S/49/mes que incluye actualizaciones de contenido, seguridad y soporte técnico.

¿Cómo es el proceso de pago?

Solicitamos 50% al iniciar el proyecto y 50% al finalizar. Aceptamos transferencias bancarias, Yape, Plin y efectivo.

¿Mi página web se verá bien en móviles?

Absolutamente. Todos nuestros diseños son "mobile-first", lo que significa que están optimizados principalmente para móviles y luego adaptados para desktop.

¿Necesito tener contenido preparado?

No necesariamente. Ofrecemos servicio de creación de contenido por S/40 adicionales. Si tienes tu contenido listo, el proceso será más rápido.
